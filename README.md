# Marco Gajardo - Personal Portfolio

Personal portfolio website built with [Astro](https://astro.build/) and Tailwind CSS. 
Designed to be fast, responsive, and easy to maintain.

## Tech Stack
- **Framework:** Astro
- **Styling:** Tailwind CSS
- **Deployment:** Vercel

## Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```
